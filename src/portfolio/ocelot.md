We use XLSForms to design forms for our clinical trials but configuring them requires a lot of manual work on Excel, which cannot be tracked on git. Ocelot is a CLI tool that allows you to design forms in YAML or TOML, with validation and linting to ensure that the forms are correct. It also provides a preview of the form, so that you can see what the form will look like before deploying it.
